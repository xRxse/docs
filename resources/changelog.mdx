NightGuildBot is actively developed, with new mechanics, balancing changes, and quality-of-life improvements introduced over time. Announcements help your community follow changes and bot availability.

## Changelog Publishing

The confirmed `/update` command publishes custom-formatted changelog messages to a designated channel without unnecessary pings. It supports listing added and removed features.

Command options, access requirements, and channel configuration have not been supplied for this wiki. Use the available command descriptions rather than assuming additional syntax.

## Announcement Types

The project supports:

- Changelogs listing added and removed features.
- Version and status announcements.
- Planned-shutdown and bot status notices.
- Custom announcement formatting.

Only `/update` is confirmed by name. Separate command names or options for shutdown and status announcements are not specified here.

## Follow Changes

Read published announcements for changes relevant to your activities. Follow shutdown and status notices before planning a session, and use current bot instructions when gameplay rules change.
