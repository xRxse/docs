Start using NightGuildBot in a Discord server where it is available. Choose a gameplay activity, read its current instructions, and explore the systems that interest you without guessing command names or requirements.

## Before You Start

You need access to a Discord server running NightGuildBot. It is a private project; a public invitation link has not been supplied for this wiki.

<Steps>
  <Step title="Find Available Commands">
    Type `/` in Discord and look for commands belonging to NightGuildBot. Use the command picker to inspect the commands available to you.
  </Step>
  <Step title="Choose An Activity">
    Select an available activity, such as fishing. Read its description and required inputs before submitting it. Follow any instructions returned by the bot.
  </Step>
  <Step title="Explore Your Progress">
    Look for available commands that show your player statistics, fishing records, or collection. Exact command names are not listed here because they have not been supplied.
  </Step>
  <Step title="Explore Guilds">
    Check the available guild interactions if you want to create or join a guild. Review the bot's instructions for invitations and membership requirements.
  </Step>
</Steps>

## What To Expect

NightGuildBot supports activity-based XP, levels, fish collections, and catch-weight tracking. Fishing includes rewards and cooldowns, but their values are not specified here. Some interactions use ephemeral responses, visible only to the person using the command.

If commands are missing, ask the server administrator to check the bot's availability and your access. This wiki does not specify the permissions needed for each command.
