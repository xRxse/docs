NightGuildBot provides slash commands for managing its gameplay systems and server activity. This page outlines the confirmed management capabilities without assigning permissions or inventing administrative command syntax.

## Management Capabilities

| Area | Supported Tools |
| --- | --- |
| Guilds | Guild management, resets, and progression management |
| Exclusive items | Granting and removing exclusive rods |
| Roles | Custom role creation and management |
| Announcements | Publishing changelogs with `/update` |

## Owner-Only Commands

Some administrative commands are restricted to the bot owner. The command list and permission requirements have not been supplied, so this wiki does not assume that Discord server administrators can use every management tool.

Check the bot's available command descriptions for required inputs. Ask the bot owner about access when a command is unavailable.

## Guild Resets

<Warning>
  Treat a guild reset as potentially destructive. Confirm the affected guild and the command's scope before running it. The exact data affected and recovery options are not specified here.
</Warning>

Guild progression management is also supported. Exact operations and their effects need a confirmed command reference.

## Exclusive Rods And Custom Roles

The bot supports granting and removing exclusive rods, including management of special items. Their distribution rules and command access are not specified here.

Custom role creation and management tools are available. The relationship between these tools and Discord or guild roles needs a confirmed reference before specific permission instructions can be documented.

## Private Responses

Some interactions use ephemeral responses, visible only to the command user. This does not mean every administrative action or announcement is private.

See [Guilds](/features/guilds), [Rods](/features/rods), and [Updates](/resources/changelog) for related systems.
